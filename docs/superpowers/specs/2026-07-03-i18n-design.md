# SerialDebug — 国际化 (i18n) 设计文档

- **功能**: 中英双语全面国际化，ResourceBundle 管理，运行时即时切换
- **版本**: v1.0 预研
- **日期**: 2026-07-03

---

## 1. 功能概述

为 SerialDebug 增加完整的中英双语国际化支持，覆盖所有用户可见文本，支持运行时无需重启即时切换语言。

### 用户故事

- 英文用户打开应用，所有界面显示英文
- 中国用户切换系统语言或手动选择中文，界面即时切换为中文
- 切换语言时 AT 指令模板库的默认指令名称也同步切换
- 偏好设置记住上次选择的语言，下次启动自动应用

## 3. 架构设计

### 3.1 模块结构

```
serial-debug-ui/src/main/java/io/github/serialdebug/ui/i18n/
├── LocaleManager.java       # 单例，持有当前 Locale + ObjectProperty
├── Messages.java            # Messages.get(key) 读取 ResourceBundle + createStringBinding()
├── messages.properties      # 默认英文资源
└── messages_zh_CN.properties  # 中文资源
```

### 3.2 LocaleManager

```java
public class LocaleManager {

    private static final LocaleManager INSTANCE = new LocaleManager();
    private static final String PREFS_KEY = "locale";
    private static final String PERSISTENCE_FILE = ".serialdebug/preferences.properties";

    private final ObjectProperty<Locale> currentLocale = new SimpleObjectProperty<>();

    private LocaleManager() {
        // Load saved preference, fall back to system locale
        Locale saved = loadSavedLocale();
        currentLocale.set(saved != null ? saved : Locale.getDefault());
    }

    public static LocaleManager getInstance() { return INSTANCE; }

    public ObjectProperty<Locale> localeProperty() { return currentLocale; }
    public Locale get() { return currentLocale.get(); }

    public void set(Locale locale) {
        currentLocale.set(locale);
        saveLocale(locale);
    }

    private Locale loadSavedLocale() { /* 从文件读取 */ }
    private void saveLocale(Locale locale) { /* 写入文件 */ }
}
```

### 3.3 Messages

```java
public class Messages {

    private static final String BASE_NAME = "io.github.serialdebug.ui.i18n.messages";

    /** Get string for current locale. */
    public static String get(String key) {
        try {
            return ResourceBundle.getBundle(BASE_NAME, LocaleManager.getInstance().get()).getString(key);
        } catch (MissingResourceException e) {
            return "!" + key + "!";
        }
    }

    /** Create a JavaFX StringBinding that auto-updates when locale changes. */
    public static StringBinding createStringBinding(String key) {
        return Bindings.createStringBinding(
                () -> get(key),
                LocaleManager.getInstance().localeProperty());
    }
}
```

### 3.4 UI 绑定模式

所有控件文本通过 `Messages.createStringBinding("key")` 绑定：

```java
// Before
Label title = new Label("AT 指令模板");

// After
Label title = new Label();
title.textProperty().bind(Messages.createStringBinding("sidebar.title"));
```

### 3.5 数据流

```
用户点击语言切换 → LocaleManager.set(locale)
  → localeProperty() 触发所有监听器
  → 所有绑定的 StringBinding 重新求值
  → ResourceBundle.getBundle() 加载新语言资源
  → Label.textProperty() 自动更新
  → JavaFX Scene Graph 重绘
```

### 3.6 语言切换入口

工具栏新增 `ToggleButton` 或 `MenuButton`：

```
ToolBar: [Clear] [Pause] [AT] [🌐 中/EN] [Search...]
```

点击切换 `LocaleManager.getInstance().set(locale)` → 所有绑定自动更新。

## 6. 实施策略

建议分批实施，每批可独立验证编译：

**批 1：基础设施**
- 创建 `LocaleManager`、`Messages`、`properties` 文件
- 编译验证

**批 2：工具栏 + IO 标签页**
- 修改 `SessionTabContent.java` 中搜索栏、发送区、AT 侧栏的所有文本
- 添加语言切换按钮
- 编译验证

**批 3：子标签页 + 其他面板**
- 修改 `DashboardPanel`、`CrcPanel`、`PortHistoryView` 等
- 编译验证

**批 4：控制器 + AT 默认值**
- 修改 `ToolbarController`、`StatusBarController`、`SendController`、`DisplayController`
- AT 默认指令名称本地化
- 编译验证

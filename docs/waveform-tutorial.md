# 波形图使用教程

波形图可以将串口接收到的数值实时绘制成折线图，适合传感器数据可视化（如温度、湿度、电压等连续数值）。

---

## 基本用法

### 1. 打开串口连接设备

在会话标签页的顶部配置栏选择端口、波特率等参数，点击 **Open** 打开串口。

### 2. 切换到波形图 Tab

在标签页内部点击 **波形图** tab。

### 3. 配置提取规则

在规则输入框中输入**提取规则**，格式为：

```
series1=regex_pattern1|series2=regex_pattern2
```

- `=` 左边是**序列名**（显示在图例中）
- `=` 右边是**正则表达式**，`()` 内是你要提取的数值
- 多个规则用 `|` 分隔

然后点击 **应用** 按钮。

### 4. 实时查看

设备发送数据时，波形图自动绘制。支持：
- **多序列叠加**：不同序列用不同颜色绘制
- **自动缩放**：Y 轴根据数据范围自动调整
- **图例**：左上角显示所有序列名称和颜色

---

## 示例

### 示例 1：单温度传感器

设备发送：`T:25.3`

规则：`T=T:([\d.]+)`

结果：一条 `T` 序列，实时温度曲线。

### 示例 2：温湿度传感器

设备发送：`T:25.3 H:60.1`

规则：`Temp=T:([\d.]+)|Humi=H:([\d.]+)`

结果：两条序列 `Temp` 和 `Humi`，不同颜色叠加。

### 示例 3：电压、电流、功率

设备发送：`V=3.30, I=0.15, P=0.495`

规则：`Voltage=V=([\d.]+)|Current=I=([\d.]+)|Power=P=([\d.]+)`

结果：三条序列同时绘制，可观察负载变化。

### 示例 4：带 +CSQ 信号值

设备发送：`+CSQ: 24,99`

规则：`Signal=CSQ: ([\d]+)`

结果：提取 `24` 绘制信号强度曲线。

---

## 注意事项

1. **正则** 必须包含至少一个 `()` 捕获组来提取数值
2. **数值** 必须是可以解析为 `double` 的数字（整数或小数）
3. **数据流向**：串口数据 → DataExtractor（正则匹配）→ ChartDataBuffer（环形缓冲区 10000 点）→ AnimationTimer（60fps）→ Canvas 绘制
4. **切换 Tab**：波形图 Tab 在选中时才消费数据，切出后停止渲染，返回后继续
5. **清空按钮**：清除已绘制的所有数据点
